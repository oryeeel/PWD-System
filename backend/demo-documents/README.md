Sample document photos for PWD-0001

These generated documents are fictional, visibly marked SAMPLE, and intended only for demonstrating the Documents screen. The physician name and signature are illustrative.

`PWD-0001-before.json` preserves the previous document photos before replacement.

Generated with the built-in imagegen tool. Prompts: a fictional medical certificate for Althea Reyes Mendoza with an illustrative physician signature; a fictional green and white PWD card for the same demo record. Both prominently state that they are samples and are not valid documents.

The `first-100` directory contains personalized sample certificates and ID cards for PWD-0001 through PWD-0100, rendered by `scripts/addSampleDocuments.ps1`. Each card uses the record's existing portrait. Certificates use a fictional physician name and illustrative signature. Timestamped JSON backups in that directory preserve both previous document fields before each run. The script verifies the exact target count, upload responses, and persisted images for every record.
